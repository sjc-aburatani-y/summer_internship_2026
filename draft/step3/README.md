## 埋めるためのヒント

### 配列（はいれつ）

`[ ]` で囲むと、値を順番に並べてまとめて持てます。

```ruby
FRUITS = [
  "りんご",
  "みかん",
  "ぶどう"
]
```

### `.sample`（ランダムに1つ選ぶ）

```ruby
FRUITS.sample  # => "みかん"（呼ぶたびに変わる）
```

### `.strip`（前後の空白・改行を取り除く）

```ruby
"  おみくじ  ".strip  # => "おみくじ"
```

これをしておくと「 おみくじ 」のように空白が入っていても反応できます。

### 関数の「返り値」

Ruby では、関数の中で**最後に書いた値**がそのまま返り値になります。
`return` を書かなくても大丈夫です。

```ruby
def greeting(name)
  if name == "たろう"
    "やあ、たろう！"   # ← name が "たろう" ならこれが返る
  else
    "はじめまして"     # ← それ以外ならこれが返る
  end
end

puts greeting("たろう")  # => やあ、たろう！
```

`build_reply` も、これとまったく同じ形になります。

### `\n`（改行）

```ruby
puts "1行目\n2行目"
# 1行目
# 2行目
```

## 実行手順

### 1. サーバーを起動する

step2 のサーバーが動いていたら、先に `Ctrl + C` で止めてください
（同じ `4567` 番ポートを使うためです）。

```bash
cd draft/step3
ruby app.rb
```

> すでに別の step のフォルダにいる場合は、先に `cd ../../` でルートに戻ってください。

### 2. ポートを公開して URL を得る（Codespaces）

1. Codespaces 下部の **「ポート(PORTS)」タブ** を開きます。
2. `4567` のポートを **公開（Public）** に変更します。
3. 表示された URL（`https://....app.github.dev`）をコピーします。

### 3. LINE に Webhook URL を登録する

**Webhook URL** に、コピーした URL の末尾に `/callback` を付けて登録します。

例: `https://xxxx-4567.app.github.dev/callback`

> step2 で登録済みで URL が変わっていなければ、そのままで大丈夫です。

### 4. 試す

自分の LINE から Bot に送ってみましょう。

- `おみくじ` → 運勢が返ってくる（何度も引けます）
- `こんにちは` → `こんにちは` がそのまま返ってくる

## うまく動かないときは

- ブラウザで公開 URL をそのまま開くと
  `おみくじBot は動いています（step3）` と表示されます。
- 反応しないときは、`ruby app.rb` を実行したターミナルに
  エラーが出ていないか確認してください。
- `undefined local variable or method '______'` と出たら
  → その行の `______` がまだ埋まっていません。
- 「おみくじ」と**完全に一致**したときだけ反応します。
  「おみくじして」では反応しません（下の「反応する言葉を増やす」で増やせます）。
- 何を送っても運勢が返るときは → TODO(4) の条件を見直してみましょう。

```ruby
OMIKUJI_RESULTS = [

```

### 反応する言葉を増やす

`build_reply` に `elsif` を足すと、キーワードを増やせます。

```ruby
def build_reply(text)
  message = text.strip

  if message == "おみくじ"
    omikuji
  elsif message == "こんにちは"
    "こんにちは！元気ですか？"
  else
    text
  end
end
```
