## 進め方

1. `step1/README.md` を読む（「埋めるところ」と「ヒント」が書いてあります）
2. `step1/send_message.rb` の `______` を上から順に埋める
3. 動かしてみる → 動いたら step2 へ
4. どうしても分からないときは、[../complete/](../complete/) の同じファイルを見る

穴になっているのは **Ruby の基礎**にあたる部分だけです。
`require` の行や、LINE へ送る通信の処理、署名チェックなどは
このフォルダでも完成させてあるので、書き換える必要はありません。

## 準備

環境変数（`.env`）と `bundle install` は**リポジトリのルート**で行います。
くわしくは [../README.md](../README.md) を見てください。

> step2 以降はどれも `4567` 番ポートを使います。
> 別のステップを試すときは、前のサーバーを `Ctrl + C` で止めてください。
