# step3: おみくじ（届いた言葉で返事を変える）

step2 の「オウム返し」から一歩進んで、**届いた言葉によって返事を変える**
ステップです。

| 送られてきた内容 | Bot の返事 |
| --- | --- |
| `おみくじ` | おみくじの結果（大吉〜大凶をランダムに1つ） |
| それ以外 | 届いた内容をそのまま返す（オウム返し） |

## ここで学ぶこと

- `if` / `else` による**場合分け**
- `def` で**自分の関数を作って呼び出す**（`omikuji`）
- **配列**と `sample` でランダムに1つ選ぶ

## 使うもの

- `LINE_CHANNEL_ACCESS_TOKEN`（返信用の鍵）
- `LINE_CHANNEL_SECRET`（届いた連絡が本物か確認する鍵）

step2 と同じ環境変数なので、step2 が動いていれば追加の準備は不要です。

## 実行手順

### 1. サーバーを起動する

step2 のサーバーが動いていたら、先に `Ctrl + C` で止めてください
（同じ `4567` 番ポートを使うためです）。

```bash
cd complete/step3
ruby app.rb
```

### 2. ポートを公開して URL を得る（Codespaces）

1. Codespaces 下部の **「ポート(PORTS)」タブ** を開きます。
2. `4567` のポートを **公開（Public）** に変更します。
3. 表示された URL（`https://....app.github.dev`）をコピーします。

### 3. LINE に Webhook URL を登録する

**Webhook URL** に、コピーした URL の末尾に `/callback` を付けて登録します。

例: `https://xxxx-4567.app.github.dev/callback`

> step2 で登録済みで URL が変わっていなければ、そのままで大丈夫です。

### 4. 試す

自分の LINE から Bot に送ってみましょう。

- `おみくじ` → 運勢が返ってくる（何度も引けます）
- `こんにちは` → `こんにちは` がそのまま返ってくる

## カスタマイズしてみよう

### 運勢の種類を増やす

`app.rb` の `OMIKUJI_RESULTS` に文字列を追加するだけです。

```ruby
OMIKUJI_RESULTS = [
  "大吉",
  "中吉",
  "超大吉" # ← 追加してみる
]
```

### 反応する言葉を増やす

`build_reply` に `elsif` を足すと、キーワードを増やせます。

```ruby
def build_reply(text)
  message = text.strip

  if message == "おみくじ"
    omikuji
  elsif message == "こんにちは"
    "こんにちは！元気ですか？"
  else
    text
  end
end
```

## 動作確認のヒント

- ブラウザで公開 URL をそのまま開くと
  `おみくじBot は動いています（step3）` と表示されます。
- 反応しないときは、`ruby app.rb` を実行したターミナルに
  エラーが出ていないか確認してください。
- 「おみくじ」と**完全に一致**したときだけ反応します。
  「おみくじして」では反応しません（上の `elsif` で増やせます）。
