## 使いかた

- まずは [../draft/](../draft/) で自分で書いてみましょう。
- 詰まったとき、書き終えたあとの見比べに、このフォルダを開いてください。
- もちろん、そのまま動かして「完成したらどう動くか」を先に確かめてもOKです。

## 準備

環境変数（`.env`）と `bundle install` は**リポジトリのルート**で行います。
くわしくは [../README.md](../README.md) を見てください。

> step2 以降はどれも `4567` 番ポートを使います。
> 別のステップを試すときは、前のサーバーを `Ctrl + C` で止めてください。
